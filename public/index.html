要怎麼開啟線上觀戰？

線上觀戰需要一台一直開著的伺服器。設定方式有兩種：

1. 自己跑：在電腦上執行 npm start，畫面會印出這台電腦的網址；再用 ?server=（那個網址） 打開這個頁面就會連過去。

2. 部署版：把 server.js 部到雲端，再把網址放進部署設定的 GAME_SERVER_URL。詳細步驟在 README 第七章。

房號是 4 個英數字，不會用到容易看錯的 I、O、0、1。
